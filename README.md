## 一、它解决什么问题 AI 模板搭建 + 内容润色

投简历最耗时间的，从来不是"写"，而是"改"。

同一个人的同一段经历，投后端岗要突出并发与稳定性，投架构岗要突出技术选型与取舍，投管理岗要突出协作与结果。于是你有了 `简历_后端_v3_最终版.docx`、`简历_架构_改.docx`、`简历_英文.pdf`……每次改完，字号、行距、分页全乱一遍。

简历工作台把这件事拆成两层：

| 层         | 内容                                               | 变化频率             |
| ---------- | -------------------------------------------------- | -------------------- |
| **内容层** | 工作经历、项目成果、技能证书、教育背景等结构化条目 | 长期积累，慢慢变多   |
| **呈现层** | 版式模板、配色、字号密度、模块顺序、区域微调       | 每投一个岗位就换一次 |

内容只维护一份，呈现随时切换。切版式只改外观，一个字都不会动。AI 模板搭建 + 内容润色

## 二、核心能力

### 1. 多版本简历，快照随时回滚

同一份资料可以并行维护多份简历，按岗位分别组织内容与版式，一键切换；每一步都留有快照，改坏了秒级回滚。支持 JSON 导入 / 导出，换设备、换浏览器都能把简历带走。

- 多简历并行管理，互不干扰
- 快照保存与秒级回滚
- JSON 全量导出 / 导入，跨设备迁移

### 2. AI 润色内容，改哪里你说了算

把口语化描述改成量化、结果导向的专业表达——**动作 + 方法 + 数据结果**，是简历能过初筛的基本语法。

AI 不会直接改你的简历：它把建议做成卡片，一条一条列出来，每条都能单独「应用」或「忽略」，应用之后还能撤销。你保留最终解释权。

- 建议卡片逐条确认，不搞一键全覆盖
- 应用可撤销，随时退回原句
- 结合当前简历上下文给建议，不用反复复制粘贴

### 3. AI 搭建模板，一句话出整套设计

描述目标岗位和想要的气质，比如「投递大厂后端，想要沉稳的深色科技风」，AI 直接搭建整套模板：配色、布局、字号密度、自定义 CSS，一次生成，实时预览，满意后一键应用。不满意，让它再出一版。

- 自然语言描述 → 整套版式参数
- 生成结果可直接预览，不覆盖原稿
- 可反复重生成，直到符合预期

### 4. 自由画布，不带任何预设意见

内置 15 套版式之外，还有一块**自由画布**：分栏、栅格、字体、质感全部交给你。写自定义 CSS，或者直接让 AI 从零生成整套样式，做真正独一无二的版式。

- 无预设布局约束，从零开始
- 支持自定义 CSS（含实时校验与安全过滤）
- 可让 AI 生成 CSS，也可自己写

### 5. 排版细节，精确到每一行

13 项全局排版参数（字号 / 行距 / 段间距 / 页边距等），加上按区域独立的字号、行高、配色微调；模块标题可以改名、可以换图标，条目可以逐条显隐，模块顺序拖拽即可调整。

一键把简历数据切换为**仅存本地浏览器**（完全不经过服务器），也可以选择云端保存、多设备同步。A4 纸张级打印导出，预览和 PDF 用同一套样式，所见即所得。

## 五、数据与安全

默认云端模式，数据落在部署机器的 SQLite 数据库，不经过任何第三方云；也可以一键切到本地浏览器模式，简历信息完全不经过服务器。

- **双存储模式**：云端保存（带滚动历史快照可回滚）/ 本地浏览器（localStorage），顶栏一键切换
- **密码与密钥加密**：密码采用 `scrypt` 加盐哈希；绑定的 AI Key 以 `AES-256-GCM` 加密落库，仅服务端解密使用，绝不返回前端
- **会话与配额**：登录态基于随机令牌（Bearer 认证）；AI 额度每日刷新
- **第三方登录**：支持 GitHub / Google OAuth 快捷登录
- **AI 请求代理**：由服务端转发，Key 不出服务端

## 七、常见问题

**Q：我的简历数据存在哪里？安全吗？**
由你选。云端模式保存在服务端数据库，换设备登录可继续；本地浏览器模式下简历信息仅存你的浏览器，完全不经过服务器。密码 `scrypt` 加盐哈希，AI Key `AES-256-GCM` 加密。

**Q：AI 额度不够用怎么办？**
订阅 Pro 后在套餐时长内不限量使用平台引擎；或绑定自有 Key，走你自己的额度，不占平台配额。

**Q：支持哪些 AI 服务商？**
OpenAI 兼容（含各类中转网关）、Anthropic、Gemini 三种协议，可自定义 `base_url`、模型名、温度。

**Q：能导出哪些格式？排版会乱吗？**
浏览器打印导出 PDF（打印对话框选「另存为 PDF」），预览与打印使用同一套样式，所见即所得。建议用桌面 Chrome / Edge 获得最佳分页效果。

**Q：和「经典本地版」有什么区别？**
经典本地版是免账号的单页编辑器，数据存浏览器 localStorage，适合快速试用；平台版增加多用户账号、云端简历、AI 配额与自有 Key 等能力，编辑功能完全一致。两个入口随时切换。

**Q：对浏览器有要求吗？**
无需安装任何软件，Chrome / Edge / Firefox / Safari 近两年版本均可；响应式适配窄屏，打印导出建议桌面浏览器。
